# Perumal Marimuthu Portfolio

A buildless portfolio site. It uses only `index.html`, `styles.css`, `script.js`, and local assets, so it can be deployed directly to GitHub Pages without installing dependencies. The portfolio highlights all current project work, including the public repositories available on the GitHub profile.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new public repository named `perumal-portfolio`.
2. Do not add a README, `.gitignore`, or license during repository creation.
3. Upload every file and folder inside this directory to the root of the new repository. Keep the `assets` folder intact.
4. In the repository, select **Settings**, then **Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose the `main` branch, select the `/ (root)` folder, and click **Save**.
7. GitHub will display the live URL after it finishes publishing. It is usually `https://YOUR_GITHUB_USERNAME.github.io/perumal-portfolio/`.

## Update content

Edit `index.html` for copy or experience details, `styles.css` for visual styling, and `script.js` for motion and interaction. Push or upload the changes to `main`; GitHub Pages automatically republishes the site.
